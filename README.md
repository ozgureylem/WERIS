# La Weris — Comida Casera (Zapopan, Jalisco)

Brand kit for a weekend home food stand. Tribute portrait of "Weli/Weris".

- `brand/` — current kit (matches the mockup): logo master, portrait seal, profile photo, two feather flags (Verde Agave, Rojo Chile), flag preview, business sheet (Spanish).
- `kit_v1_superseded/` — first kit, redrawn artwork; replaced by `brand/`.
- `exploration/` — earlier option sheets.
- `scripts/` — Python (Pillow/numpy) generators; `brand2.py` builds `brand/`.
- `reference/` — crops from the original mockup.

Notes: PNGs are for screen use, not print. The reused portrait is ~745 px; printing needs the original high-res art and a vector CMYK PDF from the printer's template (confirm size: README spec 75×300 cm vs mockup ratio ≈0.36).
